Codex Drive Sync 隐私权政策 / Privacy Policy

生效日期 / Effective: 2026-10-06

适用范围 / Scope

Codex Drive Sync 是所有者（magangwwd）个人自用的工具，只在所有者自己的电脑上运行，不向任何其他人提供。

Codex Drive Sync is a personal tool used only by its owner (magangwwd), running only on the owner's own computer, and is not provided to anyone else.

访问的数据 / Data accessed

经所有者授权后，本工具通过 Google Drive API 读取和写入所有者本人 Google Drive 中指定文件夹的文件，并读取存储容量信息。

With the owner's authorization, the tool uses the Google Drive API to read and write files in a designated folder of the owner's own Google Drive and to read storage quota information.

数据的使用与共享 / Use and sharing

  • 不收集、不出售、不向任何第三方分享任何数据。 / No data is collected, sold, or shared with any third party.
  • 没有服务器；所有处理都在所有者本地电脑上完成。 / There is no server; all processing happens on the owner's local computer.
  • OAuth 凭据只保存在所有者本地，不上传到任何地方。 / OAuth credentials are stored only locally by the owner and are never uploaded.
  • 本工具对 Google 用户数据的使用遵守 Google API Services User Data Policy，包括其中的 Limited Use 要求。 / Use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements.

撤销授权 / Revoking access

可随时在 https://myaccount.google.com/permissions 撤销本工具的访问权限。

Access can be revoked at any time at the link above.
